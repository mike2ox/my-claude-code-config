팀원과 나눈 대화 내용을 바탕으로 웹 리서치를 통해 Obsidian 인사이트 메모를 생성합니다.

Agent tool을 호출하세요. 파라미터:
- description: "인사이트 메모 생성"
- prompt: 아래 내용 전달

---

다음 대화/주제를 기반으로 인사이트 메모를 생성합니다.

오늘 날짜를 확인합니다 (`date +%Y-%m-%d`).

대화 내용:
$ARGUMENTS

## 1단계: 주제 파악

대화 내용에서 다음을 추출합니다:
- 핵심 기술 주제 (1-3개)
- 등장한 기술 용어/키워드
- 논의된 문제 또는 컨텍스트

이를 바탕으로 Obsidian 파일명 후보를 결정합니다.
형식: `{YYYY-MM-DD} {핵심키워드}.md`
예: `2026-06-25 Redis Clustering.md`

## 2단계: 웹 리서치

핵심 주제와 관련하여 WebSearch 도구로 다음 소스들을 탐색합니다 (최소 3회 검색):
- 공식 문서 (official documentation)
- StackOverflow 주요 Q&A
- 저명한 개발자의 아티클 (Medium, Dev.to, 개인 블로그)
- GitHub 관련 프로젝트 / RFC / 이슈
- 기술 트렌드 아티클

각 리소스에 대해 URL, 제목, 핵심 내용 요약을 기록합니다.

## 3단계: 방향 선택

리서치 결과를 바탕으로, 이 주제를 어떤 방향으로 심화할 수 있는지 2-4가지 방향을 파악합니다.
방향 예시:
- A) 개념 원리 deep-dive (WHY — 동작 원리와 설계 철학)
- B) 실무 적용 패턴 (HOW — 실제 코드/아키텍처 패턴)
- C) 비교 분석 (VERSUS — 유사 기술/접근법과의 차이점)
- D) 트렌드 & 미래 방향성 (WHAT'S NEXT — 커뮤니티 논의, 최신 변화)

AskUserQuestion 도구를 사용하여 사용자에게 어떤 방향으로 내용을 전개할지 물어봅니다.
질문 예시: "이 주제를 어떤 방향으로 정리할까요?" / options: 파악한 2-4가지 방향

## 4단계: 메모 생성

사용자가 선택한 방향으로 심화 내용을 작성합니다.

아래 형식을 코드블록으로 감싸서 복붙 가능하게 출력합니다.

```md
---
tags: [memo, {기술카테고리}, {세부키워드1}, {세부키워드2}]
date: {YYYY-MM-DD}
---

# {주제 제목}

## 대화 내용

{$ARGUMENTS 원문 전체를 그대로 기재}

## 심화 내용

{선택한 방향을 기반으로 리서치한 내용 — 소제목을 활용해 구조화}

## 출처

| 제목 | 링크 | 유형 |
|------|------|------|
| {제목} | {URL} | 공식문서 / 아티클 / StackOverflow / GitHub |

## 인사이트 키워드

- **{키워드}**: {이 개념에서 얻을 수 있는 인사이트 한 줄}
- **{키워드}**: {인사이트}
```

---

메모 생성 완료 후 사용자에게 안내합니다:

**파일명**: `{제안된 파일명}` 으로 Obsidian에 새 노트를 만들어 붙여넣으세요.

**일지 연결 방법**: `my-daily-log` 로 생성한 일지의 `## Reference` 섹션에 아래 wikilink를 추가하면 연결됩니다:
```
[[{파일명 확장자 제외}]]
```
